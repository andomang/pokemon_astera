# 포켓몬스터 아스테라

200년 전 가라앉았다가 "시공의 균열"과 함께 떠오른 신대륙 **아스테라**를 무대로 한 오리지널 스토리 브라우저 팬게임입니다. 설치 없이 PC와 모바일 브라우저에서 바로 플레이할 수 있습니다.

**[플레이하기](https://domang.org/pokemon)** · [소개 페이지](https://domang.org/pokeindex)

## 특징

- **오리지널 스토리:** 체육관 8곳, 악당 조직 균열단, 사천왕·챔피언, 엔딩 후 균열 지대 8곳과 배틀 타워
- **세대별 배틀 기믹:** 메가진화, 다이맥스·거다이맥스, 테라스탈, Z기술, 원시회귀, 맥스·테라 레이드
- **1025종 + 폼:** 원작 진화 조건(친밀도, 지닌 도구, 기술, 걸음 수, 지역 폼 등)과 레벨업 기술
- **전설·환상의 포켓몬:** 필드에 서 있는 전설, 배회 전설, 환상의 풀숲
- **편의 기능:** 퀘스트 화면, 지역 소개 카드, 이로치 연출, 동료 포켓몬 따라오기, 1~8배속, 모바일 가상 패드
- **계정 저장:** domang.org 회원으로 로그인하면 기록이 서버에 저장되어 다른 기기에서도 이어서 플레이

## 기술

- 순수 HTML5 Canvas + Vanilla JavaScript (빌드 도구 없이 `<script>` 순서대로 로드)
- 60Hz 고정 타임스텝 게임 루프, `async/await` 기반 이벤트 스크립트
- 배포할 때 스크립트 35개를 하나로 묶고 brotli로 미리 압축 (2.8MB → 약 400KB)
- 서버 연동(로그인·저장·선물·관리자 수정 감지)은 `game/server.js`. 서버 없이 열면 브라우저에만 저장

## 폴더

```
index.html          스크립트 로드 순서 (나중 파일이 앞 파일의 함수를 감싸서 기능을 더함)
game/core.js        입력, 사운드, 텍스트, 이미지 로딩
game/main.js        게임 루프, 필드(World), 캐릭터, 이벤트 스크립트
game/battle.js      배틀 엔진
game/mon.js         포켓몬 (능력치, 기술, 저장 형식)
game/world.js, story*.js   맵과 스토리
game/ko*.js         한국어 이름·설명
```

## 로컬에서 실행

에셋 폴더(`Pokemon Another Red_PWT_250821`)를 이 폴더와 같은 위치에 두고 정적 서버로 엽니다.

```bash
python -m http.server 8790
# http://127.0.0.1:8790/pokemon/index.html
```
